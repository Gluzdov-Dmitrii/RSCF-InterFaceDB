# Full-text source storage

This directory is local working storage for legally obtained articles, reports, patents and supplementary files. Git ignores every file here except this README.

Naming convention:

`source_id__first_author__year__short_title.ext`

Before adding a file, create or update its source record with DOI/URL, access date, license, redistribution status and SHA-256. A file may be used internally without being redistributable. Do not upload publisher PDFs or partner documents to a public DVC remote.
