## Required work

- [ ] Save exact queries, platforms, filters and UTC run time.
- [ ] Deduplicate by DOI, then normalized title and year.
- [ ] Verify bibliographic metadata against a DOI or publisher record.
- [ ] Screen each record with one controlled decision and reason.
- [ ] Extract only facts visible in an accessible source.
- [ ] Add exact locators and original units.
- [ ] Mark rights and redistribution status.
- [ ] List contradictions, missing metadata and suspected duplicates.
- [ ] Run the available validator.
- [ ] Produce a short synthesis that separates fact from inference.

## Human review request

List the highest-risk records first. For each, state the exact field or claim that needs human adjudication and why it changes the research decision.

## Completion report

- records discovered / deduplicated / screened / included;
- evidence items extracted;
- validation failures;
- inaccessible sources;
- top three gaps;
- proposed next bounded batch.
