# Application obligations and open compliance questions

Date of audit: 2026-09-05

This memo is a research-management reading of the local application and competition
documents, not legal advice. The signed agreement and current RSF guidance take
precedence and are not present in the repository.

## Research-facing program commitments

- First period: data model, metadata rules, normalized literature corpus,
  representative systems, reproducible MD pilots, database v1, preliminary
  relationships and material for the first paper.
- Second period: database expansion, targeted gap filling, ML with uncertainty and
  applicability limits, active learning, continuum transfer, final database and a
  second paper.
- Planned result: a registered database intellectual-property object and journal
  publications in leading venues.
- Exact dates, administrative counters and budget constraints remain in the ignored
  private audit until publication is cleared.

## Separation controls for the MWCNT partner branch

1. Assign every dataset, sample and expense a funding/project provenance label.
2. Keep confidential partner files and derived sensitive tables outside public Git and
   outside a public data release.
3. Define the public scientific question independently of confidential field data.
4. Approve publication and background/foreground IP terms before experiments begin.
5. Do not charge an experimental program to the grant unless the budget and agreement
   authorize it.
6. Preserve an auditable boundary between public bibliographic evidence, grant-funded
   work and partner-funded work.

## Decision owner and deadline

The PI owns the formal clarification. It must be closed before committing publication
counts, partner scope or an experimental budget.
